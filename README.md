# Student Management System (Version 2)

An improved Python project that manages and analyzes student data.

## Features

* Add students and their marks
* Display all students
* Pass/Fail system
* Count total students
* Calculate average marks
* Find highest marks

## How to Run

```bash
python student_management.py
```

## Concepts Used

* Functions
* Lists & Dictionaries
* Loops
* Conditional Statements

* Improved logic building
* Better function structuring
* Data analysis using Python
